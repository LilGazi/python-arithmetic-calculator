# Python Arithmetic Calculator 🧮

A beginner Python calculator that performs basic arithmetic operations using functions and conditional statements.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- User-selected arithmetic operations

## Technologies Used

- Python

## How It Works

The program asks the user to select an arithmetic operation:

`+` for addition  
`-` for subtraction  
`*` for multiplication  
`/` for division

It then asks for two numbers and uses a corresponding Python function to calculate the result.

## Example

```text
Enter arithmetic operation +, -, *, /: *
Enter number: 8
Enter number: 5
Result: 40.0
